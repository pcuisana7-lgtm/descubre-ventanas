# Descubre Ventanas

**Estudiante:** Paolo Vinicio Cuisana Pérez
**Destino turístico asignado:** Cantón Ventanas – Provincia de Los Ríos, Ecuador
**Enfoque:** Turismo rural, naturaleza, gastronomía y actividades locales

## Descripción del proyecto

Portal web de **Descubre Ventanas**, una agencia de turismo ficticia creada con fines académicos para promocionar el cantón Ventanas, en la provincia de Los Ríos, Ecuador. El sitio presenta los principales atractivos naturales y rurales del cantón —como el malecón sobre el río Zapotal, las playas fluviales de Zapotal y Sibimbe, las Cascadas San Jacinto, el río Oncebí en la parroquia Chacarita, y la Ruta Rural del Maíz—, además de paquetes turísticos, información institucional de la agencia y un formulario de contacto/reserva.

El proyecto fue desarrollado como examen práctico de la asignatura, aplicando estructura semántica HTML5, formularios, CSS3 (Box Model, Flexbox, Grid, diseño responsive) y control de versiones con Git y GitHub.

> Toda la información turística fue investigada a partir de fuentes públicas sobre el cantón Ventanas (Wikipedia, ViajandoX, entre otras). El logotipo es una ilustración vectorial (SVG) elaborada para este proyecto; las fotografías de los atractivos son imágenes reales incorporadas por el estudiante.

## Páginas del sitio

| Página | Descripción |
|---|---|
| `index.html` | Inicio: presentación de la agencia, hero, destinos destacados y llamado a la acción. |
| `destinos.html` | Seis atractivos turísticos del cantón Ventanas con foto, descripción, ubicación y actividad. |
| `servicios.html` | Cinco paquetes/tours turísticos con descripción y precio referencial. |
| `nosotros.html` | Historia, misión, visión, valores y razones para visitar Ventanas. |
| `contacto.html` | Formulario HTML5 de contacto/reserva y mapa de ubicación. |

## Tecnologías utilizadas

- HTML5 (estructura semántica: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (selectores de etiqueta, clase y combinados; pseudo-clases `:hover`/`:focus`; Box Model; Flexbox; CSS Grid; `@media` queries)
- JavaScript básico (menú móvil y validación visual del formulario)
- Git y GitHub para control de versiones
- GitHub Pages para el despliegue
